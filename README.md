# Library Management System

A simple **Library Management System** developed in C as a group project for learning and applying basic Data Structures and C programming concepts.

## 📌 About the Project

The Library Management System helps manage basic library operations such as adding, searching, issuing, returning, deleting, and displaying books.

The project is designed using simple C programming concepts so that the working of the system is easy to understand.

## ✨ Features

- Add a new book
- Search for a book using Book ID
- Issue a book
- Return a book
- Delete a book
- Display all books
- Check book availability status
- Menu-driven interface

## 🛠️ Technologies Used

- **C Programming**
- **Structure**
- **Array**
- **Functions**
- **Loops**
- **if-else**
- **switch-case**

## 📚 Data Structure Used

The project uses an **Array of Structures** to store and manage book records.

Each book record contains:

- Book ID
- Book Name
- Author Name
- Book Status
